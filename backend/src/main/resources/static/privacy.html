隐私政策

本隐私政策说明了我们如何收集、使用和保护您的个人信息。使用我们的网站（“全球油电成本计算器”），即表示您同意本政策中所述的数据处理方式。

1. 信息收集

我们不会主动收集您的个人身份信息。当您使用我们的计算工具时，输入的数据（如油价、油耗等）仅在您的浏览器中处理，不会上传到我们的服务器。

2. Cookie 和 Web 信号

与许多其他网站一样，我们使用 Cookie 来存储有关访客偏好的信息，记录用户访问的页面信息，并根据访客的浏览器类型或其他信息定制网页内容。

3. Google AdSense

Google 作为第三方供应商，使用 Cookie 在我们的网站上投放广告。Google 对广告 Cookie 的使用使其能够根据用户对我们网站和互联网上其他网站的访问向用户投放广告。用户可以通过访问 Google 广告和内容网络隐私政策来选择停用 Cookie。

4. 第三方广告服务

第三方广告网络使用技术将出现在我们网站上的广告和链接直接发送到您的浏览器。当这种情况发生时，它们会自动接收您的 IP 地址。第三方广告网络还可能使用其他技术（如 Cookie、JavaScript 或 Web 信号）来衡量其广告的有效性和/或个性化您看到的广告内容。

5. 隐私政策的变更

我们可能会不时更新我们的隐私政策。我们建议您定期查看本页面以获取任何变更。这些变更在发布到本页面后立即生效。

6. 联系我们

如果您对本隐私政策有任何疑问，请通过我们的联系页面与我们联系。
